# EELOG Generator - 仲裁模拟日志生成器

> 适用范围：用于生成模拟日志，以便学习日志结构和进行离线调试。
> 本工具为纯前端单文件应用，无需安装、无需联网，双击即用，不会上传任何数据。

## 1. 快速开始

1. 打开本目录下的 **`index.html`**（双击即可，支持 `file://` 本地直接打开）。
2. 第 1 步选择任务模式：**防御 / 镜像防御 / 拦截**（三选一）。
3. 第 2 步选择任务节点（下拉列表会按模式筛选，括号内为内置参考生息/时），填写 1-4 个队员名。
4. 第 3 步填写期望生息（选择“/小时”或“/分钟”）、清场效率（可留空）和轮数。
5. 先点**“推算预览”**查看计算结果，再点**“生成并下载 EE.log”**，文件会自动命名为 `EE.log`。

## 2. 参数说明

| 参数 | 说明 |
|---|---|
| 任务模式 | 防御按波输入（标准 81 波 = 27 轮，单轮约 82 秒，上限 90 波）；镜像防御按轮输入（标准 9 轮，单轮约 503 秒，上限 12 轮）；拦截按轮输入（标准 10 轮，单轮约 414 秒，上限 12 轮）。总时长默认按模式节拍和轮数估算，并带少量随机波动；也可手动覆盖 |
| 任务节点 | 防御 27 张图、镜像防御 2 张图、拦截 13 张图；每个节点附有内置参考值（/时） |
| 队伍成员 | 最终固定 4 人。第 1 个视为主机。留空的槽位自动填充 7–15 位随机英文名 |
| 期望生息 | 按全 Buff 口径计算。超出当前模式可生成范围的数值会受上限限制，预览会显示实际计算结果 |
| 任务总时长 | 留空时自动估算（防御 82 秒/轮、拦截 414 秒/轮、镜像 503 秒/轮，并带少量随机波动）；也可手动输入，例如 `37:45`、`1h7m50s`、`2264`（秒）。纯数字小于 300 时按分钟处理。输入会锁定预览与生成文件的总时长 |
| 清场效率 | 手动填写时，会直接决定有效敌人事件数；留空时按当前模式、轮数、时长和生息自动估算。定义为无人机出现率相对理论 20% 的达成率。`Spawned` 峰值仅用于完整性对照 |
| 轮数 | 防御填波数（标准 81，自动按 3 波一轮换算，非 3 倍数就近取整）；拦截填轮数（标准 10）；镜像防御填轮数（标准 9，切换模式自动填入，均可改）。决定日志中出现多少次轮次结算；镜像波次按实测环波递增段计数 |

页面中把鼠标悬浮在每个选项的 `?` 或卡片上，会弹出同样的文字说明。

## 3. 计算方式

- 轮次：`DefenseReward::TransitionOut` 出现次数；主机时长 = `SS_STARTED → 末次结算`。
- 全 Buff 生息 = 无人机 × 0.06 × 5.9 + 轮次保底与红利（前 4 轮每轮 +0.21，之后每轮 +0.30）。页面会根据期望、轮次和时长估算无人机数。
- 清场效率 = 无人机 ÷（有效敌人 − 无人机）÷ 0.2 × 100。页面会据此估算有效敌人事件数，再按波次预算写入逐怪记录；`Spawned` 计数持续递增，仅用于完整性对照。
- 生息效率 = 全 Buff/时 ÷ 节点基准 × 100。
- 无人机数会加入少量确定性扰动，使结果不会与输入简单地一一对应。留空时，总时长和清场效率会按当前参数自动估算；手动填写时长或清场效率后，对应结果会严格采用输入值。

## 4. 生成文件的结构

- **启动头**：集群、构建、版本、缓存与连接等基础信息，以及关卡加载和登录流程。
- **大厅**：组队行、节点滚动、投票/任务名行（含 `_EliteAlert` 后缀）、关卡资源路径（含模式关键字）、实体创建、开局状态切换。
- **任务体**：防御包含波次预算、逐怪生成、无人机记录和轮次结算；拦截包含领地争夺事件和轮次结算；镜像防御包含环波播报、连续结算和轮次结算。时间戳递增，计数连续。
- **收尾**：结算回调、经验/信用行、统计上传与档案写回。

## 6. 常见问题

- **页面动效没加载？** 确认 `vendor/` 与 html 在同一目录下且未改名；无动画时表单与生成功能不受影响。
- **生成大轮次很慢？** 拦截/镜像单轮约 400 秒仿真时长，行数多属正常，进度条会显示合成进度；建议拦截/镜像不超过 8 轮。
- **解析出的数值与输入差一点？** 时间抖动与取整会导致 ±1% 级偏差，生成结果面板会回显“实际达成”值，以该值为准。
- **文件名？** 固定为 `EE.log`。
